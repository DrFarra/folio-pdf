Folio 0.4.1 — source and build information

Application source: folio-0.4.1-fuente.zip, provided beside the installer.
License: AGPL-3.0-or-later, full text in LICENSE.
Dependency versions/integrities: package-lock.json and both Cargo.lock files.
Native Windows build: npm ci; npm run desktop:build.
Required tools: Node 22+, Rust MSVC, Visual Studio C++ Build Tools/Windows SDK,
WebView2. See README.md and https://v2.tauri.app/start/prerequisites/.

Native macOS universal build: npm ci; npm run desktop:macos.
Required tools: macOS 14+, Node 22+, Rust Apple Darwin and Xcode Command Line
Tools. The script installs the Intel and Apple Silicon Rust targets if missing.
Output: src-tauri/target/universal-apple-darwin/release/bundle/{macos,dmg}.
Mac builds use ad-hoc signing, without Apple notarization. See README.md and
the Mac release's build/runtime evidence. Windows acceptance is not Mac testing.

MuPDF.js 1.28.1 npm package is used without modification.
Complete official C/TypeScript/WASM build source, including thirdparty sources:
  sources/mupdf-1.28.1-source.tar.gz (beside the application source archive)
  https://mupdf.com/downloads/archive/mupdf-1.28.1-source.tar.gz
SHA-256:
  dc94c60b2537e2ac9a2d379dd3801545f84a3a302d15c9da358362a1270707c3
Repository/tag: https://github.com/ArtifexSoftware/mupdf/tree/1.28.1

Rebuild MuPDF.js independently from that source archive:
  Install Node and the Emscripten SDK.
  Extract the archive; cd mupdf-1.28.1-source/platform/wasm.
  npm install
  EMSDK=/path/to/emsdk bash tools/build.sh
The upstream script installs/activates Emscripten 4.0.8, uses BUILD=small and
default feature/define settings. It creates dist/mupdf.js, mupdf-wasm.js,
mupdf-wasm.wasm and TypeScript declarations. See tools/build.sh for details.
For a source build of Folio, use this package through npm/local packaging, then
run npm run build and npm run desktop:build. Rebuilding this upstream source
is documented but was not executed for this release; the tested WASM is the
unmodified published npm package, pinned by its package-lock integrity.
No byte-for-byte reproducibility claim is made for a build on another machine.

Other dependencies are published source packages. Exact npm registry URLs and
Cargo crate source-download URLs are recorded in dependency-licenses.json.
Keep the full source, instructions and license notices available with any
redistributed binary as required by the applicable licenses.

The Windows release is an unsigned x64 development build. The Mac release is
an ad-hoc signed universal development build for Intel and Apple Silicon.
The original 0.2.0 release was cross-compiled from Linux. Build and runtime
verification for 0.4.1 is recorded in docs/acceptance-windows.md. Windows installation, WebView2 dialogs and PDF file associations still
require acceptance tests on actual Windows 10/11 machines.
